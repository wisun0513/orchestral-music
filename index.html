① 모임 날짜 선택

주일 예배위원 제외

해당하는 주일 예배위원 명단을 붙여넣으세요. 붙여넣은 텍스트에서 이름만 인식하여 적용합니다. 해당 명단은 군악대 출결 대상에서 제외되고 사유는 예배위원으로 표시됩니다. 조슬기, 최성빈은 예배위원 명단에 포함되어도 기본 참석이며, 부분참석 입력 시에는 부분으로 표시됩니다.

제외 0명

0/0 예배위원 명단

접속한 주의 일요일을 기준으로 예배위원 명단을 적용합니다. 붙여넣은 텍스트에서 이름만 인식하여 적용합니다. 최종출결 1은 해당 주 위원만, 최종출결 2는 전체 예배위원을 표시하며 대상이 아닌 사람은 이름/해당없음으로 나옵니다.

출결 대상 0명

엑셀 적용

선택한 모임의 최종출결 2를 파트별 명단 순서대로 엑셀에 추가합니다. 7개 열: 날짜 / 파트 / 이름 / 출결 / 사유 / 상세사유 / 부분시간. 이름과 출결은 별도 열로 저장하며 날짜(A열)는 YYYY-MM-DD 형식으로 통일합니다.

업로드한 파일의 다른 날짜·다른 모임 기록은 유지합니다. 같은 모임·날짜의 출결은 추가로 쌓지 않고 마지막 엑셀 전송/적용 내용으로 교체합니다. 이전 6열 양식도 7열로 변환됩니다. 파일을 올리지 않으면 8개 모임의 새 엑셀을 만듭니다. 파일과 전송 기록은 이 화면에서만 보관되며 서버로 전송하지 않습니다.

모임별 기간 선택

8개 모임의 시작일·종료일을 각각 정하면 그 기간에 해당하는 요일의 날짜가 모두 표시됩니다. 필요한 날짜를 체크해 엑셀에 적용하거나 선택 다운로드하세요. 기록이 없는 날짜는 목록에 표시되지만 출결이 생성되지는 않습니다. 같은 모임·날짜에 대해 다시 적용하면 이전 출결을 새 내용으로 교체합니다.

이번에 엑셀에 전송·적용한 최신 기록

선택 다운로드에는 위에서 체크한 모임·날짜의 마지막 적용 기록만 포함됩니다. 전체 다운로드에는 업로드한 파일의 다른 날짜·모임 기록도 포함되며, 같은 날짜·같은 모임은 마지막으로 전송·적용한 기록 한 번만 저장됩니다.
